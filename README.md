# ZZVJ kartičky

Interaktivní kartičky k přípravě na Zkoušky základního výcviku jezdce ČJF
(všeobecná licence, ZZVJ-V). 260 otázek v 19 okruzích.

Otevři: `index.html` (jeden soubor, žádné závislosti, funguje i offline).

Zdroje odpovědí: skripta a pravidla České jezdecké federace (cjf.cz),
doplňkově přípravné otázky z equos.cz. Neoficiální studijní pomůcka.
